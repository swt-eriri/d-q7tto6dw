对照 A8 tool 回调核验 一起看。

DSH 进程调 MCP 时怎么认人：每个进程一把令牌

机制：进程令牌（身份与权限 0006 第 1.1、5 节）。例子：张三的 DSH 进程里，Agent 调 mem0 记忆服务；王经理的自进化进程调行内 MCP 服务；评估和探测进程。

这一页想让你讲得出：tool 回调已经能认人了，为什么 MCP 还要另一套；令牌从签发到作废的一生；五种令牌各代表谁、放行什么；为什么不设过期、风险能不能接受。 M07 = 身份与权限，你负责的 0006（签发、校验）；DSH 适配层 = 0002（起进程、交给守护程序）；M05 = MCP 代理（拿令牌问「是谁」，再判能不能调）。

① 先分清四对词

tool 回调 ≠ MCP 调用

tool 回调
经桥接插件回调平台，平台按 DSH 会话查执行凭据，精确到这一次执行（A8）。
MCP 调用
DSH 进程直接按 MCP 协议发给 MCP 代理，只能带进程环境变量里的东西，所以只能精确到这个进程。
平台业务 tool（取数、读知识）走回调；mem0、行内 MCP 服务走 MCP。

路由键 ≠ 用户 ID

路由键
DSH 进程的门牌号，一个路由键一个进程。用户进程的路由键就是用户 ID。
其他路由键
evolution:管理员 ID、评估账号 ID、eval-aux:评估 ID、system:probe。
身份模块按路由键的前缀判断这是哪种令牌、代表谁。

进程令牌 ≠ 外部 MCP 服务的凭据

进程令牌
只在平台内部用：DSH 进程 → MCP 代理，告诉代理「我是谁」。
连接凭据
代理再去访问外部 MCP 服务时，用的是这条连接自己的凭据（0010）。令牌不外发。
外部服务看不到平台的令牌。

作废 ≠ 过期

作废
进程回收、代表对象被停用或失去权限时，主动作废。
不设过期
令牌没有到期时间。运行中进程的环境变量从外面改不了，过期只能重启进程。
「随进程有效」：进程在，令牌在；进程回收，令牌作废。

种类路由键代表谁MCP 代理放行什么
用户用户 ID这个用户按资源模块的对象授权；可向 mem0 传用户身份

④ 为什么这样做 每条都是「不这样会坏在哪」

1. tool 回调已经能认人了，为什么 MCP 还要另一套？

MCP 调用不经桥接插件，是 DSH 进程按 MCP 协议直接发给代理的，平台没机会按 DSH 会话去查执行凭据；DSH 也不能把平台令牌带进 tool 调用。能带的只有进程环境变量里的东西，所以每个进程放一把令牌，由守护程序注入，MCP 配置把它读进请求头。

2. 为什么不设过期？风险是什么？

设短期过期：DSH 进程可能连着跑好几天，运行中进程的环境变量改不了，令牌一过期只能重启进程，打断用户。

风险：Agent 主进程的读文件工具不经沙箱，可能读到进程环境变量里的令牌（还没测，并入 DSH 测试用例 V15）。即使读到，也只能以同一个身份经代理调用，代理照样判权，不扩大权限。沙箱里执行的命令读不到（沙箱清掉名字含 TOKEN 的环境变量）。

3. 停用时为什么要批量作废令牌，校验时不是还会查状态吗？

停用应该立刻、干净地失败。批量作废只多一条 UPDATE，库里一眼能看出令牌已作废；校验时查代表对象的当前状态，是第二道保险。

4. 为什么签发的入参还是路由键，不改成明确的类型？

MCP 调用记录要按路由键存，评估辅助令牌的评估 ID 只在路由键里。解析五种前缀只有十几行代码，不值得为此改接口和表。

5. 自进化令牌为什么签发和校验时都要查管理员的能力？

和 B1「按发起人当前的能力」一样：管理员被降级后，他的自进化进程不能继续带着管理员身份调 MCP。降级时身份模块同一事务作废他的自进化令牌，校验时再查一次能力。

⑤ 它不保证什么

  • 只精确到进程，不精确到执行。同一个进程里的所有会话共用这把令牌。
  • 开发环境单进程时，所有用户共用一把令牌。代理会认成同一个人，只能用于没有真实数据的环境。
  • 生产按用户分进程有个前提还没测：多个进程各带各的令牌、代理能区分（DSH 测试用例 V16，待复测）。不通过的话，要按人判权的 MCP 服务改成平台业务 tool、走桥接插件，进程令牌退化为只区分进程种类。V16 影响 P2 的 MCP 代理，不影响 P0、P1。
  • 令牌可能被 Agent 读到（V15 待测），但不扩大权限。
  • 停用后旧进程很快又启用的小坑：旧进程的令牌已作废，MCP 调用会失败，直到进程重新拉起（B6）。

⑥ 自测 先自己想，再点开

1. 张三的 DSH 进程调 mem0，代理怎么知道是张三？

请求头里带着进程令牌；代理调身份模块的 verifyCallerToken，身份模块按令牌的 SHA-256 查到这一行，未作废、张三是启用的 → 返回种类「用户」、路由键、主体张三。代理据此判断，并可以向 mem0 传张三的身份。

2. 王经理的自进化进程能用 mem0 吗？

不能。自进化令牌不放 mem0，也不传最终用户身份；只放这个自进化 Agent 版本勾选的 tool。

3. 发布探测进程能调行内 MCP 服务的 tool 吗？

不能。探测令牌只能列 tool，不能调（用来核对 tool 清单，A5 第 5 步「探测」）。

4. 进程回收时作废令牌失败了，会怎样？

由 DSH 适配层的清理任务重试；作废接口重复调用结果相同，重试是安全的。进程已经不在了，旧令牌也没有进程能用。
