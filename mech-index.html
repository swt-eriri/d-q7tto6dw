学习清单：我负责的机制，一个一个过

目标：0004 后端框架、0006 身份与权限里的每个机制，都做到讲得清、判断得了别人的改动、验收得了代码。

范围只限这两份 RFC 写了的东西；0017 开放 API 等定稿后再加。别人的模块只讲到接口为止。整理日期 2026-11-17。

每一题，做到这四点就算过

  1. 用项目里的真实场景按时间讲一遍：哪个进程、谁的代码、数据库里多了什么。
  2. 说出为什么不用更简单的做法。
  3. 说出在哪一步崩了会怎样、谁来接手。
  4. 说出哪些地方要靠写代码的人做对，也就是验收时看什么。

给出题人（GPT 或别的 AI）的规则

  • 只考本清单里的题；每题围绕列出的关键问题，问 1–2 个，四点答到就往下走。
  • 例子只用项目里的真实场景，不用积分、转账这类通用例子。
  • 我答不上的基础概念（事务、锁、线程……），补一两句够用就回到题上，不展开成课。
  • 每题结束标进度：答对了 / 听懂但没验证 / 没覆盖。讲过不等于答对。
答对了 口试里自己讲对 部分答对 一部分讲对，其余没覆盖 听懂未验证 讲过但没自己复述 没覆盖 机制级 要能按时间走一遍；架构级 知道做什么、为什么即可

进度取自 11-17 的口试笔记第 10 节。点开每一题看场景和关键问题。
