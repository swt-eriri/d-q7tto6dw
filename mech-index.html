目标：0004 后端框架、0006 身份与权限里的每个机制，都做到讲得清、判断得了别人的改动、验收得了代码。

范围只限这两份 RFC 写了的东西；0017 开放 API 等定稿后再加。别人的模块只讲到接口为止。整理日期 2026-11-17。

每一页看完，能做到这四点就算懂了

  1. 用项目里的真实场景按时间讲一遍：哪个进程、谁的代码、数据库里多了什么。
  2. 说出为什么不用更简单的做法。
  3. 说出在哪一步崩了会怎样、谁来接手。
  4. 说出哪些地方要靠写代码的人做对，也就是验收时看什么。
机制级 要能按时间走一遍；架构级 知道做什么、为什么即可

按建议顺序排：先 0004（P0 就要用），再 0006，最后综合。点题目展开看场景和要能回答的问题；点右边「进入」直接看页面。顶部「目录」在每一页都能用。
